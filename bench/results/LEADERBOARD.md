# CircuitPilot PCB Bench — leaderboard

Each model designs and repairs boards with CircuitPilot's tools; the design it leaves behind is scored 0–100 per task (schematic 35, placement 15, routing 25, DRC 15, behaviour 10) and averaged. "Design" = the 8 tasks from an empty project, "Repair" = the 6 broken boards; DRC clean / fully routed count the PCB tasks. Tokens / task = average tokens sent to the model (the conversation is re-sent at every step, so this grows with the number of steps) and generated by it, per task. How to run: [bench/README.md](../README.md).
